## My workflow

**Discover → Design → Build → Test → Refine**

- **Discover:** Explore the problem, user needs, and technical options.
- **Design:** Establish information hierarchy, visual direction, and interaction patterns.
- **Build:** Direct implementation with modern tools and AI-assisted engineering.
- **Test:** Review behavior, usability, responsiveness, and technical edge cases.
- **Refine:** Iterate until the result is coherent, accessible, and deliberate.
